# permutation specification

the Hemera permutation (profile 0.4) is a Poseidon2 instantiation over the [[Goldilocks field]]. it operates on a state of 16 field elements and applies 60 rounds of nonlinear substitution and linear diffusion, with the S-box x⁷ in every round.

## structure

```
input state [16 elements]
    │
    ▼
initial linear layer       M_E
    │
    ▼
6 full rounds              add_rc + S-box(all 16, x⁷) + M_E
    │
    ▼
48 partial rounds          add_rc(state[0]) + S-box(state[0], x⁷) + M_I
    │
    ▼
6 full rounds              add_rc + S-box(all 16, x⁷) + M_E
    │
    ▼
output state [16 elements]
```

total: 60 rounds (6 + 48 + 6). the initial linear layer is a one-time pre-mixing step applied before the first round; it carries no constants and no S-box.

| parameter | value |
|---|---|
| width t | 16 |
| S-box | x⁷, every round |
| full rounds R_F | 12 = 6 + 6 |
| partial rounds R_P | 48 |
| external layer M_E | circ(2·M4, M4, M4, M4), M4 the Poseidon2 reference block ([[matrices]]) |
| internal layer M_I | 1 + diag(d), d the Poseidon2 reference diagonal for Goldilocks t = 16 ([[matrices]]) |
| round constants | 192 external + 48 internal = 240 ([[constants]], [[bootstrap]]) |

## S-box: x⁷

the power map x → x⁷, applied to all 16 state elements in a full round and to state[0] in a partial round.

d = 7 is the least invertible exponent for this field. invertibility requires gcd(d, p − 1) = 1; p − 1 = 2³² · 3 · 5 · 17 · 257 · 65537, so d = 3 and d = 5 fail and d = 7 is the smallest valid choice. x⁷ maps 0 to 0 and is a bijection of F_p.

computation, 4 multiplications at multiplicative depth 3:

```
x² = x · x
x³ = x² · x
x⁴ = x² · x²
x⁷ = x³ · x⁴
```

proof-system cost: with witnesses x² and x³, the constraints `x·x = x²`, `x·x² = x³` (degree 2) and `x³·x³·x = x⁷` (degree 3) define the S-box; hemera's constraint accounting counts 4 constraints per S-box. the trace API (`rs/src/trace.rs`) emits `[x², x³]` for every S-box, full and partial.

## full round

```
for i in 0..16:
    state[i] += RC_FULL[round * 16 + i]     ── add round constant
    state[i]  = state[i]⁷                    ── S-box
M_E(state)                                   ── external linear layer
```

there are 12 full rounds, in two groups:
- rounds 0–5: initial full rounds (before the partial rounds)
- rounds 6–11: terminal full rounds (after the partial rounds)

each full round consumes 16 round constants from `RC_FULL[192]`.

## partial round

```
state[0] += RC_PARTIAL[round]               ── add round constant (one element)
state[0]  = state[0]⁷                       ── S-box on one element
M_I(state)                                   ── internal linear layer
```

there are 48 partial rounds, indexed 0–47. each consumes one round constant from `RC_PARTIAL[48]`.

## initial linear layer

before the first full round, the external matrix M_E is applied once to the input state:

```
M_E(state)                                   ── pre-mixing
```

this mixes all state elements before the first S-box application (Poseidon2 §5).

## linear layers

see [[matrices]] for the construction, the concrete values, their derivation and the conditions they satisfy.

### external matrix M_E (full rounds)

```
M_E = circ(2·M4, M4, M4, M4)

M4 = [ 5 7 1 3 ]
     [ 4 6 1 1 ]
     [ 1 3 5 7 ]
     [ 1 1 4 6 ]
```

algorithm:
1. apply M4 to each 4-element chunk of the state
2. compute column sums: `s[k] = Σ state[j+k]` for `j ∈ {0,4,8,12}`, `k ∈ {0,1,2,3}`
3. add the appropriate column sum to each element: `state[i] += s[i mod 4]`

### internal matrix M_I (partial rounds)

```
M_I = 1 + diag(d₀, d₁, ..., d₁₅)
```

where `1` is the all-ones matrix. the multiplication is:

```
state'[i] = d[i] · state[i] + Σ state[j]   for j = 0..15
```

## round constants

240 Goldilocks field elements, partitioned as:

```
RC_FULL[192]    — 12 full rounds × 16 elements per round
RC_PARTIAL[48]  — 48 partial rounds × 1 element per round
```

indexing:
- full round `r` (0 ≤ r < 6, initial): constants at `RC_FULL[r*16 .. r*16+16]`
- full round `r` (6 ≤ r < 12, terminal): constants at `RC_FULL[r*16 .. r*16+16]`
- partial round `r` (0 ≤ r < 48): constant at `RC_PARTIAL[r]`

constants are generated by the self-bootstrap procedure (see [[bootstrap]]). no external PRNG is used.

## complete algorithm

```
function permute(state: [GoldilocksField; 16]):
    // initial linear layer
    state = M_E(state)

    // 6 initial full rounds
    for r in 0..6:
        for i in 0..16:
            state[i] += RC_FULL[r * 16 + i]
            state[i] = state[i]⁷
        state = M_E(state)

    // 48 partial rounds
    for r in 0..48:
        state[0] += RC_PARTIAL[r]
        state[0] = state[0]⁷
        state = M_I(state)

    // 6 terminal full rounds
    for r in 6..12:
        for i in 0..16:
            state[i] += RC_FULL[r * 16 + i]
            state[i] = state[i]⁷
        state = M_E(state)

    return state
```

## round numbers and margins

the round counts follow a stated rule (hemera#15, restated per layer in `audit/campaign.md` §3.3): each outer full layer keeps at least three times the full rounds a published attack crosses or skips (two), and the partial layer at least 1.5 times the longest published subspace trail through the internal layer (≈ 30 at t = 16). 6 ≥ 3 · 2 and 48 ≥ 45.

margins against each attack line, as computed in `audit/campaign.md` §3.1 (scripts in `audit/campaign/`):

| line | 0.4 margin | how |
|---|---|---|
| statistical / differential (R_F ≥ 6 rule of Poseidon2) | R_F 12: +6 full rounds | Poseidon2 statistical inequality |
| interpolation (Poseidon2 inequality, M = 128) | x⁷ rounds 60 against 26 needed: +34 rounds | `p2rounds.py` |
| Gröbner (Poseidon2 inequalities 1–3, ePrint 2023/537 binomial term) | all satisfied; least admissible R_P at R_F 12 is 14 (48 = 3.4×); binomial term 2^521 against 2^128 | `p2rounds.py` |
| univariate CICO-1 degree | 7^60 = 2^168.4 > p: univariate root finding over F_p does not apply | computed |
| resultant degree (ePrint 2026/1905 form) | 7^60 = 2^168 or 7^72 = 2^202, above 2^128 | computed |
| affine-line linearization through the partial layer | stops at 15 of 48 partial rounds: +33 | hemera#2 `research/partial_subspace.py` |
| subspace trails through M_I (ePrint 2026/967, 2026/1792) | linear trails ≤ t − 1 = 15: +33; nonlinear ≈ 30: +18 | published bounds |
| infinitely long subspace trails (ePrint 2020/500) | excluded: charpoly(M_I^i) irreducible for i = 1..32 | [[matrices]] |
| generic: capacity 512 bits | 2^256 | sponge bound |

the algebraic margin is measured by the public cryptanalysis campaign (`audit/campaign.md`), not claimed by a degree bound.

## properties

| property | value |
|---|---|
| invertibility | every step is a bijection: gcd(7, p − 1) = 1, M_E and M_I invertible |
| S-box differential uniformity | x⁷: at most 6 solutions of (x + a)⁷ − x⁷ = b, so ≤ 6/p |
| multiplications per permutation | 12 · 16 · 4 = 768 (full S-boxes) + 48 · 4 = 192 (partial S-boxes) + 48 · 16 = 768 (M_I) = 1 728 |
| S-boxes per permutation | 240 (960 constraints in hemera's accounting) |
